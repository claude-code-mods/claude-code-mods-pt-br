ripple

> Tradução para português (Brasil) pelo projeto claude-code-mods-pt-br. O autor e a licença originais estão no final. A versão original em inglês está em [README.en.md](README.en.md).

Escolhe o esforço de raciocínio para cada prompt e um worker para cada tarefa delegada, mantém o cache aquecido e mostra para onde foi cada requisição.

## Instalação

```
/plugin install ripple@claude-code-mods-pt-br
```
