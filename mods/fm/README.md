Firstmate Calm

> Tradução para português (Brasil) pelo projeto claude-code-mods-pt-br. O autor e a licença originais estão no final. A versão original em inglês está em [README.en.md](README.en.md).

Animação de trabalho do veleiro e transcrição restrita à conversa, com preferência de modo calmo compartilhada entre sessões.

## Instalação

```
/plugin install fm@claude-code-mods-pt-br
```
