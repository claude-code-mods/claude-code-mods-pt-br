engineer

> Tradução para português (Brasil) pelo projeto claude-code-mods-pt-br. O autor e a licença originais estão no final. A versão original em inglês está em [README.en.md](README.en.md).

Um kit de metodologia de engenharia agêntica disciplinada: entrada, descoberta de critérios de aceite, especificação, planejamento, implementação, verificação e endurecimento.

## Instalação

```
/plugin install engineer@claude-code-mods-pt-br
```
