shared-session

> Tradução para português (Brasil) pelo projeto claude-code-mods-pt-br. O autor e a licença originais estão no final. A versão original em inglês está em [README.en.md](README.en.md).

Compartilhe uma sessão por link ou com sua equipe; colegas entram com seu próprio Claude Code e acompanham cada turno ao vivo.

## Instalação

```
/plugin install shared-session@claude-code-mods-pt-br
```
