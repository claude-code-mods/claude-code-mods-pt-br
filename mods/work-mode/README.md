work-mode

> Tradução para português (Brasil) pelo projeto claude-code-mods-pt-br. O autor e a licença originais estão no final. A versão original em inglês está em [README.en.md](README.en.md).

Modos de sessão: auto (sem perguntas no meio da tarefa), out (delegar trabalho em lote) e wrap (convergir e finalizar).

## Instalação

```
/plugin install work-mode@claude-code-mods-pt-br
```
